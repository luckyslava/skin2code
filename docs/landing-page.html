常见问题

关于即视UI 的几个高频问题。

即视UI 是什么？

即视UI 是一款主打微信小程序的 AI 界面代码生成工具（D2C，Design to Code）：上传设计稿图片或用 AI 生成界面图，自动生成原生小程序代码，亦可导出网页与 React Native。由北京汐小满科技有限公司开发。

生成的小程序代码是什么格式？

原生微信小程序代码：WXML 页面结构、WXSS 样式、JS 逻辑与数据绑定、app.json 配置和图片资产一次生成，可直接导入微信开发者工具运行，不绑定私有框架。

没有设计稿可以使用即视UI吗？

可以。内置 AI 生图能力，用文字描述界面即可生成界面图，再从界面图生成小程序代码。也支持上传自己画的设计稿或产品截图。

已有项目没有设计稿，能帮我改版吗？

可以，这正是即视UI 的独特能力：LLM 直接读取你现有页面代码，反向生成设计稿（支持 A/B 两版对比），挑中哪版就融合回你的代码，其余逻辑逐字保留——祖传项目改版不用再补画设计稿。

生成的代码能直接用吗？

生成的代码会先经过编译校验、结构守卫与类名自洽检查再落地，避免静默坏代码；布局由排列引擎输出符合开发规范的 flex 结构。复杂页面建议在编辑器里微调后落盘。

代码如何交付到我的项目？

通过浏览器 File System Access API 授权本地工程目录，生成的代码与图片资产直接写回项目文件夹，支持增量更新。
